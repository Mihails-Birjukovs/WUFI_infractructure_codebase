## REF & HEMP source report

The principal source for the new examples is *WUFI Unified Report, draft v1.4* (2026), especially:

- Sec. III.F and Appendix B: exterior climate and WAC construction.
- Sec. V.D–E, Sec. X and Appendix G: residual multiscale decomposition, HODMD and DMDc.
- Appendix I.1: **retained project Python script** for WAC generation using `pvlib`, including astronomical-night correction, bracketed same-hour clear-sky index interpolation and Erbs diffuse decomposition.
- Appendix I.3–I.4: **reconstructed Python reproducibility implementations** for multiscale and delay DMDc because the historical Phase-4 temporary source scripts were not retained.
- Appendix J: historical code provenance and publication-freeze guidance.

Consequently, the Python WAC module is an **adaptation of retained report code**, with CLI/input validation; the multiscale/DMDc modules are **cleaned-up reference implementations of the reconstructed methodology**, **not recovered byte-identical historical files**. The standalone DMD/HODMD module is a **new reference implementation** of the documented modal-analysis method, not a claim to have recovered previously used code.

This distinction matters: reproduce historical numerical claims against the **frozen original tables/figures and source audit** independently, rather than treating a fresh run of reconstructed code as an automatic match.

## Historical versus physical solar coordinates

The historical WAC reconstruction uses 56.97° N, 24.17° E and fixed UTC+2. The report states physical test-house coordinates of 56.985411° N, 24.085193° E; it documents that the historical solar result was retained after a coordinate sensitivity check. Both coordinate sets must remain identified. CLI coordinate overrides are for new/reprocessed cases, **not a silent replacement of historical provenance**.

## Not bundled

Private REF & HEMP source reports, raw MongoDB/sensor recordings, station audit tables, actual WAC inputs, compiled WUFI models, and calibration/result archives are not publicly redistributed here. The minimal Python fixtures are synthetic. No sample graph or numeric outcome generated by these fixtures is an experimental conclusion.

## Algorithmic boundaries

- The WAC adaptation assumes solar radiation is **global horizontal irradiance** and inputs are hourly, end-labelled, and in a known **fixed standard time**. It does not reconstruct a raw MongoDB source collection by itself.
- Multiscale decomposition with centered rolling windows loses validity near edges and gaps; guard against empty/zero-variance bands.
- DMD/HODMD is an unconstrained linear fit to the supplied trajectory. Eigenvalues and modes depend on centering, rank, embedding and sampling.
- Delay DMDc identifies a **predictive linear input-state map**; no physical causality follows from this fit alone. Impulse simulations correctly propagate lagged input history, unlike the compact pseudocode in the report that sets the lagged input vector only at the first step.
- Python smoke tests validate mathematical invariants on synthetic data. Scientific equivalence to REF & HEMP's historical Phase-4 results remains a separate check.

A future publication-ready archive should freeze an exact Git commit, requirements versions, authorized source/data checksum manifest and externally archived baseline results.
